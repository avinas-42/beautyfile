Beauty File

Google Workspace™ add-on for Google Docs™

Beauty File applies targeted formatting from the document sidebar: letter scope (all text, uppercase-only, or lowercase-only), font, size, bold, italic, underline, and color—without changing case across the whole document.

The add-on runs on Google Apps Script™ when you use it in Google Docs™. It accesses only the open document to apply formatting you trigger in the panel.
